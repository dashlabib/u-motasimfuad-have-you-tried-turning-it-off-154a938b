One funny line from a hopeless tech support agent to a desperate customer: the classic "turn it off and on again" prescribed, with total cheerful confidence, for a house fire — and if that fails, the agent's grand plan is to escalate the customer to Tier 2. The humour is the agent's uselessness, never the customer.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (and a copy to `entry.txt` in the repository root). The program is deterministic, uses only the Python standard library, and needs no network access.

## Entry

> Don't panic — turn the whole house off and on again, and if the fire's still there I'll escalate you to Tier 2.
